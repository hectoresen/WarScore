# Código de conducta

WarScore da la bienvenida a contribuciones de cualquier persona. Mantén una comunicación respetuosa, constructiva y centrada en el problema técnico. No se toleran acoso, discriminación, amenazas ni la publicación de datos personales.

Los mantenedores pueden moderar o rechazar aportaciones que incumplan estas normas.

Para informar de una conducta inapropiada, contacta de forma privada con el responsable del repositorio mediante GitHub; evita publicar datos sensibles en issues abiertos.
