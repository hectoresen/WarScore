# Política de seguridad

WarScore es un addon de WoW Forever en desarrollo activo. No se garantiza compatibilidad o soporte para todas las versiones del cliente.

**No publiques vulnerabilidades explotables ni credenciales en issues.** Si GitHub permite *Private vulnerability reporting* en el repositorio, utiliza **Security → Report a vulnerability**. En caso contrario, ponte en contacto con el mantenedor por un canal privado.

Incluye versión del addon y del cliente, pasos de reproducción, impacto y cualquier evidencia que pueda compartirse de forma segura. No envíes contraseñas, cuentas de WoW ni datos personales.
